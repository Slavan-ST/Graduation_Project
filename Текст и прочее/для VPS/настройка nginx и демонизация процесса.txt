Для этого создадим файл в директории /etc/systemd/system/ с расширением .service


путь к директории приложения
WorkingDirectory=/home/slavan/API/Основное приложение/ClientServer/WebAPI/bin/Release/net8.0/publish

путь к опубликованной dll
ExecStart=/home/slavan/API/Основное приложение/ClientServer/WebAPI/bin/Release/net8.0/publish/WebAPI.dll          

Команды (для меня)
cd /etc/systemd/system/
sudo nano /etc/systemd/system/kestrel-test.service

Для начала создаётся сервис (АПИ в моём случае)
!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!
[Unit]

Description=Test API

[Service]
WorkingDirectory=/home/slavan/API/main/ClientServer/WebAPI/bin/Release/net8.0/publish
ExecStart=/usr/bin/dotnet ./WebAPI.dll
Restart=always
RestartSec=10
SyslogIdentifier=dotnet-example
User=slavan
Environment=ASPNETCORE_ENVIRONMENT=Production

[Install]
WantedBy=multi-user.target

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

Настройка nginx для прослушивания порта 8888 и перенаправление его на 8080 локалхоста
Создать файл /etc/nginx/sites-available/aspnetcore.conf  

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!
server {
    listen 8888;
    location / {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection keep-alive;
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

Создание сслыки на файл
sudo ln -s /etc/nginx/sites-available/aspnetcore.conf /etc/nginx/sites-enabled/aspnetcore.conf


сам запуск сервисов

sudo systemctl enable kestrel-test.service
sudo systemctl start kestrel-test.service

рестарт
sudo systemctl restart kestrel-test.service
stop
sudo systemctl stop kestrel-test.service

проверка состояния 
sudo systemctl status kestrel-test.service


Тестирование порта
ls | nc -l -p 8888
